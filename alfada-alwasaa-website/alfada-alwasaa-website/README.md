# موقع شركة الفضاء الواسع — AL-FADA AL-WASAA

كود مصدري كامل لموقع التعريف بالشركة، مع جميع المرفقات (الصور والشعار) المستخرجة من ملف البروفايل الرسمي.

---

## 1) محتويات الملف المضغوط

| المجلد | المحتوى |
|---|---|
| `source/` | الكود المصدري الكامل للموقع (Next.js 16 + React 19 + Tailwind CSS 4) — جاهز للتشغيل والتعديل |
| `attachments/web-ready/` | الصور والشعارات الجاهزة للويب — **هذه هي النسخ المستخدمة فعلياً في الموقع** |
| `attachments/pdf-extracted-images/` | الصور الخام المستخرجة من ملف الـ PDF (بأبعادها الأصلية) |
| `attachments/pdf-pages/` | لقطات لصفحات البروفايل العشرة (مرجع للمحتوى الأصلي) |

## 2) المتطلبات

- **Node.js إصدار 20 أو أحدث**: https://nodejs.org
- مدير الحزم npm (يأتي مع Node.js)

## 3) التشغيل

افتح الطرفية (Terminal) داخل مجلد `source` ثم نفّذ:

```bash
npm install
npm run dev
```

ثم افتح المتصفح على العنوان: **http://localhost:3000**

## 4) بناء نسخة للنشر (اختياري)

```bash
npm run build
```

ينتج هذا الأمر مجلد `out/` يحتوي نسخة ثابتة (HTML/CSS/JS) جاهزة للرفع على أي
استضافة ثابتة (Netlify / Vercel / cPanel / أي سيرفر ملفات)، ويمكن أيضاً فتح
`out/index.html` مباشرة في المتصفح بعد تعديل مسارات الملفات أو استخدام خادم ثابت.

## 5) أين أعدّل؟

- **النصوص والأقسام**: كل قسم في ملف مستقل داخل `source/src/components/site/`:

  | الملف | القسم |
  |---|---|
  | `header.tsx` | القائمة العلوية |
  | `hero.tsx` | الواجهة الرئيسية |
  | `about.tsx` | من نحن |
  | `sectors.tsx` | قطاعاتنا |
  | `services.tsx` | خدماتنا |
  | `position.tsx` | مكانتنا |
  | `vision-mission.tsx` | الرؤية والرسالة |
  | `track-record.tsx` | سابقة الأعمال |
  | `why-us.tsx` | لماذا نحن |
  | `conclusion.tsx` | الخاتمة |
  | `footer.tsx` | التذييل |

- **الصور**: مجلد `source/public/profile/` — استبدل أي صورة بنفس الاسم لتظهر في الموقع مباشرة.
- **الألوان**: `source/src/app/globals.css` — الكحلي `#0a3453` والذهبي `#c6954a` (مأخوذة من هوية البروفايل).
- **الخط**: `source/src/app/layout.tsx` — خط Cairo (Google Fonts).
